#    check_automation_workflow_thesis

## Description
This project is still under construction.
This project will later on offer a Github workflow that is to be implemented in every upcoming project regarding the
Methodhub website. It will check for missing required files, license, README construction (Maybe also crude readme content,
commentary and code quality). 

## Use Cases
- For every Uploaded Content on the Methodhub Website (will be required)

## Input Data
The input data is the Github repository itself.

## Output Data
The form of the Output Data will still be determined and is subject to change.
The workflow will create a report folder in what the output data (report) will be found.
The output data will be created using a bot from Github, which commits and pushes the report. So problems with 
branch protection might occur.
